Round 1 entry for make.fun's "Everyday Things, Two Lines, Longer Run" bounty: explain one everyday thing to a 10-year-old in two lines — the first line builds the analogy, the second says what the analogy maps and what it leaves out.

The entry: "A toaster is a time machine that turns soft white bread into crisp brown toast in two minutes. It maps the quick change and the waiting, but it leaves out that a time machine goes both ways, and a toaster never unbrowns toast."

## Run it

```sh
python3 main.py
```
